#### 3.4.6 D6, hot lists and vertices where the GE reads them cheaply [D]

Written by builder2, 2026-11-27 10:12, under the same rulings as §3.4.1 (shares a lead only, counted at half; no per-item µs from any drawsplit row). D6 comes after D1-D5 in the order (07:2x), so it is priced on what D1-D3 leave, and said where it would stand alone.

- **What D6 is [D at this head].** The brief's D6 (lab briefs/draw_main.md:53): "hot vertex data and lists where the GE reads them cheaply, off the CPUs' main-RAM misses.
